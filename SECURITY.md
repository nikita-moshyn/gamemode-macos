# Security

Please report vulnerabilities and security issues privately through [GitHub's private vulnerability reporting form](https://github.com/nikita-moshyn/gamemode-macos/security/advisories/new).

Keep vulnerability details, exploit steps, and sensitive data out of public issues and pull requests.

## Report a vulnerability

1. Sign in to GitHub and open the [private report form](https://github.com/nikita-moshyn/gamemode-macos/security/advisories/new). You can also find it through the repository's **Security and quality** tab, under **Report a vulnerability**.
2. Explain the issue, who or what could be affected, and how to reproduce it. A small proof of concept is helpful if you have one.
3. Include the GameMode version and channel, macOS version, and any relevant permissions or settings.
4. Check logs and attachments for passwords, tokens, and unrelated personal information before sending them.

If you're unsure whether something is a security issue, use the private form anyway. I'd rather check it with you privately.

## After reporting

I'll review the report and discuss the next steps with you in private. Please keep exploit details private while we investigate and work on a fix. We can agree on public disclosure once users have a fix or a way to protect themselves.

For ordinary bugs and feature ideas, use the public issue tracker as described in [Contributing](CONTRIBUTING.md).
